# 长截图拼合工具：产品需求

版本：V1.0 需求草案  
产品形态：桌面 GUI 软件，首版以 Windows 10/11 为目标平台  
参考图片：用户提供的 `IMG_8150.PNG` 至 `IMG_8155.PNG`。图片仅用于理解流程和界面，不把图片中的聊天内容作为产品指令。

## 1. 产品目标

让用户把多张手机或电脑截图拼成一张完整图片，并在可视化界面中检查、修正每一条拼缝。重点解决 iOS 长截图过长时可能被缩小或压缩的问题：导出时按源图像素计算画布，不为适应预览窗口而降低输出分辨率。

软件提供三种模式：

| 模式 | 输入与顺序 | 默认拼合行为 |
| --- | --- | --- |
| 长截图 | 同一页面连续滚动所得的 2 张及以上截图，按内容先后排序 | 自动找相邻截图的重叠区域、对齐并去重；每条拼缝独立审核和修正 |
| 竖拼 | 2 张及以上独立图片，按从上到下排序 | 直接首尾排列，不自动删去重叠内容；可手动调整接缝 |
| 横拼 | 2 张及以上独立图片，按从左到右排序 | 直接首尾排列，不自动删去重叠内容；可手动调整接缝 |

首版处理本地静态图片，不负责手机端截屏、录屏、云同步或 OCR 重建内容。

## 2. 核心原则

1. **原图与编辑参数分离**：导入图片不被覆盖；拼缝、裁剪、清理、顺序等以可撤销的项目参数保存。
2. **自动结果可见且可质疑**：自动匹配不能保证每一处都正确。每条拼缝显示状态、匹配位置和问题原因，用户可以逐条复核。
3. **预览缩放与导出尺寸独立**：屏幕上缩小显示不改变导出的原始像素；任何降采样都必须由用户主动选择。
4. **鼠标职责明确**：普通状态拖动画布；选中拼缝后拖动待对齐图；`Shift + 左键拖动` 始终平移画布，不改拼合结果。
5. **长图优先保证完成**：输出尺寸触及格式或内存限制时给出真实尺寸与可选解决方案，不能静默压缩。

## 3. 用户流程

1. 打开软件，拖入图片或点击“添加图片”。可一次导入多张，也可追加。
2. 在模式切换器选择“长截图 / 竖拼 / 横拼”；缩略图显示顺序，可拖动排序、删除、追加。
3. 长截图模式自动分析每对相邻图片。界面出现拼缝及状态：通过为 `✓`，需检查为 `!`；计算中显示进度。
4. 在中央画布查看结果。点击蓝色拼缝进入该拼缝的编辑状态，用鼠标或方向键修正；再次点击同一拼缝或按 `Esc` 退出。通过检查后可标记“已确认”。
5. 按需使用切分、删段、裁边、清理。清理的重点是去除滚动条，以及统一重复截图中的顶部状态栏与底部固定栏。
6. 点击“导出”，查看最终像素、预计大小、格式和限制提示；导出至用户指定位置。可选择保存可继续编辑的项目文件。

## 4. 输入与项目管理

### 4.1 导入

- 支持文件选择、多选、拖放文件及文件夹；首版至少支持 PNG、JPEG、WebP，读取时自动按 EXIF 方向显示，保留原文件名。
- 对损坏、不支持、无法读取或尺寸为零的图片逐项提示；有效图片继续导入。
- 默认按导入顺序排列，不依赖文件名猜测。提供按文件名/拍摄时间排序，排序前显示预览，允许手动拖动覆盖。
- 混合分辨率、不同宽高比、不同设备截图均可导入，但长截图自动匹配不可靠时应提示手动处理。
- 缩略图标注序号、文件名、尺寸；排序、删除、追加后仅重算受影响的拼缝。

### 4.2 项目

- 支持新建、打开、保存项目；项目记录源文件路径、顺序、模式、拼缝偏移、裁剪、清理设置和确认状态。
- 编辑后显示未保存标记；关闭或打开另一项目时提供保存、放弃、取消。
- 源文件丢失时列出缺失项并提供重新定位，不用低清预览替代原图导出。
- 撤销/重做覆盖排序、拼缝移动、切分、删段、裁边、清理和设置变更；导出不写入编辑历史。

## 5. 拼合规则

### 5.1 长截图自动匹配

- 相邻图片逐对检测有效内容区域和重复部分；既评估纵向重叠，也允许少量横向位移。连续滚动截图的默认方向为纵向。
- 识别并降低状态栏、导航栏、底部输入栏、悬浮按钮、滚动条等固定元素的匹配权重，避免把相同固定 UI 当作真正的内容重叠。
- 结合图像特征和局部像素验证，产出候选位置、置信度、有效重叠长度、横向偏移及冲突区域。纯色区、重复列表项、动态内容、动画或时间变化应降低置信度。
- 自动匹配成功时，去掉后一张与前一张重复的内容，生成连续预览；不得在接缝处保留两份相同内容或吃掉唯一内容。
- 结果状态：`✓ 自动匹配` 表示达到阈值且无明显冲突；`! 需检查` 表示低置信度、多解、无足够重叠、明显断层或清理冲突。阈值为内部参数，界面展示可读原因，不把“成功”当作绝对正确。
- 允许用户重新分析当前拼缝、全部重新分析，或把某条拼缝重置到自动建议。重新分析前保留可撤销的手动结果。

### 5.2 手动拼缝

- 每条拼缝具有独立的上下/左右位移及重叠裁切量。点击画布上的蓝色拼缝或拼缝列表项，进入编辑状态；再次点击当前拼缝或按 `Esc` 退出。
- 编辑状态显示两侧图像的半透明重叠预览、基准线、差异高亮和当前偏移数值。默认固定拼缝前的内容，移动拼缝后的相邻图片；用户可选择切换固定侧。
- **鼠标左键拖动待对齐图**：在屏幕上大范围、连续地沿上下及左右移动拼合位置；鼠标移动量换算为原图坐标，缩放改变时视觉拖动仍稳定。需要时可在工具栏选择“仅上下 / 仅左右 / 双向”约束。
- **方向键**：每按一次按源图坐标移动 1 像素；按住连续移动。移动方向与当前活动图像在画布上的方向一致；聚焦文本输入框时不触发。
- 鼠标滚轮默认使整个画布快速上下滚动；`Ctrl + 滚轮` 以指针所在位置为中心缩放预览；`Shift + 左键拖动` 平移整个放大后的画布，不改变拼缝偏移、裁切或确认状态。
- 非拼缝编辑状态，画布空白处或图像上的左键拖动用于平移整个画布；画布平移不改变拼合位置。
- 明确显示“编辑拼缝”或“浏览画布”状态与光标形态。离开拼缝时保存当前参数；每次有效移动使原有 `✓` 确认失效，状态改为“手动待确认”。
- 可“确认拼缝”“恢复自动”“取消本次调整”。确认只表示用户接受当前结果，不改变原图。

### 5.3 竖拼与横拼

- 默认按图片原像素排列。竖拼以统一宽度、横拼以统一高度生成画布；尺寸不一致时默认保留原图尺度、在空白区域补透明，并提供对齐方式与间距设置。
- 可单独选择“按目标宽/高等比缩放”，这属于显式的有损/重采样操作，预览和导出尺寸需清楚标注。
- 每条接缝都可手动调位置、间距和对齐；竖拼主要上下排列，横拼主要左右排列，不自动去重或声称存在重叠。

## 6. 编辑工具

| 工具 | 需求 |
| --- | --- |
| 切分 | 在指定画布位置把当前片段分为两段，供单独移动、删除或导出；切分前显示位置线，可取消 |
| 删段 | 删除选中的源图或切分后的片段；展示影响范围，操作可撤销；删除后重算相邻拼缝 |
| 裁边 | 可按全局统一边距裁剪，也可单张调整；预览展示裁剪框和最终宽高，默认不改原图 |
| 清理滚动条 | 默认可开启；检测通常位于左右边缘的细长滚动指示条，预览掩膜，可对单张或全部应用；不确定时不自动涂抹正文 |
| 清理状态栏 | 可开启；从第一张、最后一张或指定图片取一份顶部状态栏，重复出现的状态栏被去除或替换。支持“替换 / 裁剪 / 留白”三种处理方式 |
| 状态栏时间 | “保留来源时间 / 统一为 9:41 / 自定义时间”；仅在选择“替换”且来源素材可处理时生效。显示替换区域预览，不承诺自动生成不存在的真实系统图标 |
| 清理底部固定栏 | 对聊天输入栏、导航栏等重复固定区域提供类似的保留一次、裁剪或手动框选能力；默认不自动删除正文 |

清理操作须提供处理前后对比、作用范围、可撤销记录。检测失败或可能覆盖真实内容时标为“需检查”，允许关闭该项清理。参考图 `IMG_8154.PNG`、`IMG_8155.PNG` 的设置含义，但桌面版不需要相册权限或“保存后删除原素材”。

## 7. 导出

- 格式至少支持 PNG 与 JPEG；PNG 为默认选项，保留无损像素。透明画布导出 JPEG 时须选择背景色。可按需支持 WebP、TIFF。
- 默认输出像素由源图与编辑参数计算，不因预览缩放、窗口尺寸或长图长度自动缩小。导出面板同时显示实际像素尺寸、格式、估计文件大小和所需磁盘空间。
- 若目标尺寸超过格式、编码器、操作系统或可用内存限制，提前明确提示；提供“拆分为多张原尺寸图片”作为首选替代，并允许用户主动选择降低尺寸。禁止静默压缩或生成截断文件。
- 拆分导出时按用户指定的最大高度或目标文件数划分，尽量避开拼缝，顺序编号，并可设置相邻图小范围重叠以便阅读。每片保持原宽度与像素比例。
- 大图渲染应分块处理和编码，预览使用独立的低内存图层；导出过程中显示进度、可取消。取消或失败时清理不完整的临时输出。
- 导出成功后提供打开文件、打开所在文件夹；项目源文件保持不变。

## 8. 状态、异常与提示

| 情况 | 界面行为 |
| --- | --- |
| 正在分析 | 相邻拼缝显示进度或忙碌状态，仍可浏览已完成区域；禁用该拼缝确认 |
| 自动通过 | 拼缝显示 `✓` 和简短匹配信息；可展开查看重叠长度、偏移与差异 |
| 需检查 | 拼缝显示 `!`，说明如“重复内容有多个候选”或“重叠太短”；允许手动修正和确认 |
| 手动调整后 | 显示“手动待确认”；确认后显示 `✓ 手动确认`，两者视觉可区分 |
| 图片损坏/缺失 | 列出文件名与原因；跳过或重新定位，不让结果静默缺图 |
| 动态内容差异 | 高亮异常区，保留两张源图对比，用户决定拼缝位置或切除动态区域 |
| 导出超限 | 显示具体尺寸和限制，提供分段导出或用户主动缩放 |

## 9. 非功能需求

- 首版 Windows 10/11，鼠标和键盘为主，支持系统 DPI 缩放与高分辨率显示器。
- 图片处理在后台执行；滚动、缩放、切换拼缝不应被整张长图解码持续阻塞。目标是普通近年桌面电脑导入 20 张约 1170×2532 的 PNG 后，画布操作保持可响应，具体性能门槛以原型实测确认。
- 预览不得把敏感截图上传网络；首版离线运行。项目文件仅引用本地源图，不将原图嵌入项目，除非用户执行明确的“打包项目”。
- 操作按钮有文字或悬停提示；状态不能只靠颜色表达；快捷键可在菜单中发现。错误信息应说明可执行的修复办法。
- 默认保存最近一次模式与清理设置，但新项目的破坏性选项保持关闭。

## 10. 验收场景

1. 导入 4 张连续聊天截图，排序正确时自动给每条拼缝独立状态。点击某条蓝色拼缝进入编辑，再次点击退出；不影响其他拼缝。
2. 选中拼缝后左键大幅拖动，下方图片相对上方移动；按方向键一次精确移动源图 1 像素；退出后重新进入保留位置。
3. 在编辑状态按 `Shift + 左键拖动`，只移动整个画布；拼缝偏移数值不变。滚轮上下滚动；`Ctrl + 滚轮` 缩放，拼合数据不变。
4. 自动匹配不确定时出现 `!` 与原因。用户修正后显示“手动待确认”，点击确认变为 `✓ 手动确认`。
5. 开启滚动条清理、状态栏替换后，能查看掩膜和前后对比；可仅对某张取消处理，撤销后恢复原效果。
6. 导入两张无重叠的独立图片，竖拼和横拼均能按顺序排列；切换模式时明确提示现有手动拼缝参数如何处理。
7. 超长输出不因画布预览缩小而减小像素；触及单文件限制时提示并能分段以原尺寸导出。
8. 保存项目、关闭、重新打开后，图片顺序、拼缝偏移、裁边、清理设置及确认状态一致。

## 11. 待产品确认的默认值

这些取值不妨碍绘制 UI 原型，开发前应通过真实截图样本确认：自动匹配通过阈值、滚轮一次滚动的屏幕距离、默认清理状态、分段导出的默认最大高度、项目文件扩展名，以及是否在首版支持 macOS。
