# 长截图拼合工具：模拟 UI 与交互需求

版本：V1.0 原型规格  
适用：桌面可视化 GUI；用于先制作可点击、高保真原型，随后可作为实现依据。

## 1. 设计定位

参考图 `IMG_8150.PNG` 的模式入口、`IMG_8151.PNG` 至 `IMG_8153.PNG` 的蓝色拼缝与编辑工具，以及 `IMG_8154.PNG`、`IMG_8155.PNG` 的清理选项。桌面布局采用工作区结构：左侧素材与拼缝列表、中央大画布、右侧当前工具参数，避免把手机底部菜单直接放大。

界面首先让人看见真实拼接结果。蓝色表示当前可操作拼缝；`✓`、`!` 和“手动待确认”同时使用图标与文字，不能只用颜色暗示质量。预览背景采用深色中性底，图片使用原色显示，拼缝辅助线不写入导出图片。

## 3. 页面与组件

### 3.1 空白与导入状态

- 首屏直接显示可拖放区域、添加图片按钮和三模式切换；不做营销首页。
- 导入后立即显示缩略图与画布，后台匹配逐条完成。图片数量少于 2 时提示继续添加，导出可只针对单张原图，但拼缝工具禁用。
- 左侧缩略图可拖动排序。拖动时显示插入线；右键菜单提供上移、下移、删除、查看源图信息。

### 3.2 拼缝列表与画布

- 每条相邻关系在列表中有独立行：序号 `2→3`、状态图标、状态文字和问题摘要。点击列表行定位画布上的拼缝并进入编辑。
- 画布拼缝为蓝色细线与可点按的中间把手，悬停出现“点击编辑拼缝 2→3”提示；已选中时加粗并显示两图重叠预览。`✓` 与 `!` 应贴近拼缝但不遮住正文。
- 拼缝显示应有一个最小可点击区域，即使预览缩小也容易选中；放大时线宽保持视觉稳定。对长图滚动到任意位置，左侧拼缝列表始终可用于跳转。
- 自动通过的拼缝仍可进入编辑。需检查的拼缝允许跳转到差异最大的区域。

### 3.3 顶栏与工具栏

- 顶栏：菜单、项目名与未保存标记、三模式分段控件、导出按钮。
- 画布上方：适应窗口、实际像素 100%、缩放减/加、拼缝对比、差异叠层开关。
- 底部工具栏：拼缝、切分、删段、裁边、清理；工具图标加文字，悬停显示用途。状态栏右侧持续显示当前模式、画布实际像素和预览缩放比例。
- 切换到切分、删段、裁边或清理时，右栏变为对应参数，不让相互无关的参数堆在一屏。

### 3.4 右侧拼缝检查面板

进入拼缝编辑时，面板显示：当前 `第 2/3 条拼缝`、自动/手动状态、问题原因、重叠长度、X/Y 源图像素偏移、固定侧选择、移动方向约束、透明度滑块、差异显示、恢复自动、取消本次调整、确认拼缝。

数值输入允许直接键入整数像素；输入后与画布实时同步。确认按钮只在未确认或改变后可用。若没有可用自动建议，“恢复自动”不可用并说明原因。

### 3.5 清理面板

- 三个独立开关：清理滚动条、统一状态栏、清理底部固定栏；每项可设全部图片或指定图片。
- 滚动条项显示检测侧别、掩膜宽度、逐张开关和前后对比。
- 状态栏项显示处理方式“替换 / 裁剪 / 留白”、来源图片、时间“保留来源 / 9:41 / 自定义”，以及受影响区域。只在“替换”时显示时间与来源控件。
- 底部固定栏项提供保留来源、自动建议区域、手动框选。点击“应用预览”后在画布高亮修改区域；不能直接提交隐藏修改。
- 参考图中的“相册权限”“保存后询问删除原素材”不属于桌面原型主流程。

### 3.6 导出面板

显示格式、背景色（JPEG 时）、原始像素尺寸、预估大小、输出路径。尺寸可导出时提供“导出单张”；超出单文件限制时显示限制原因和“按原尺寸分段导出”，并提供每片最大高度、相邻片重叠量及命名预览。降低尺寸为单独显式选项，必须显示输出比例与新像素值。

## 4. 鼠标与键盘交互契约

| 输入 | 浏览画布 | 编辑某条拼缝 |
| --- | --- | --- |
| 左键单击蓝色拼缝 | 进入该拼缝编辑 | 再次单击当前拼缝则退出；单击另一拼缝则切换 |
| 左键拖动图片/画布 | 平移整个画布 | 拖动活动侧图像，连续改变拼缝 X/Y 偏移；可大幅移动 |
| `Shift + 左键拖动` | 平移整个画布 | 仅平移整个画布，**不改变**拼缝或清理参数 |
| 鼠标滚轮 | 快速上下滚动画布 | 快速上下滚动画布，**不改变**拼缝 |
| `Ctrl + 鼠标滚轮` | 以鼠标位置为中心缩放画布 | 同左，**不改变**拼缝 |
| `↑ ↓ ← →` | 默认按 1 px 屏幕单位平移视口；可在设置中关闭 | 每次移动活动侧图像 1 个**源图像素**，方向与箭头一致 |
| `Esc` | 取消当前临时工具或选区 | 退出拼缝编辑，保留已做调整；“取消本次调整”需单独点击 |
| `Ctrl + Z / Ctrl + Y` | 撤销 / 重做编辑操作 | 同左，包括每次拖动作为一条操作记录 |

交互优先级：`Shift + 左键拖动` 始终高于拼缝拖动；`Ctrl + 滚轮` 始终高于普通滚动；文本输入框获得焦点时方向键用于文本编辑；拼缝把手上的单击与拖动由移动阈值区分，拖动不会误触发“退出”。拖动开始时固定当前活动拼缝和活动侧，直到松开鼠标，不因指针离开图片而中断；拖动结束后写入一条可撤销记录。

缩放范围建议 10%–800%，并提供“适应宽度”“适应整个结果”“100%”三个快捷操作。缩放是预览变换，右侧 X/Y 偏移数字始终为源图像素。鼠标拖动应显示即时位移浮标，例如 `X +12 px  Y -38 px`。

## 5. 关键状态原型

### A. 自动拼合完成

画布显示连续结果，拼缝线上方有 `✓ 自动匹配` 或 `! 需检查`。左侧列表中 `!` 优先排序可筛选，但图片顺序保持不变；右侧显示总计 `3 条拼缝 · 2 已通过 · 1 需检查`。

### B. 点击蓝色拼缝

当前拼缝变亮，非当前拼缝弱化；画布局部显示两张图片的半透明重叠和差异区域。右侧列出候选位置与偏移。状态栏提示“编辑拼缝 2→3”；鼠标在活动图像上变成移动光标。

### C. 拖动/方向键调整

活动图片随鼠标连续移动，参考图片保持固定；蓝线与差异预览实时更新。`Shift` 按下时鼠标光标变为抓手，拖动只平移视口。每次方向键按下后 X/Y 值改变 1，且状态变为“手动待确认”。

### D. 退出与确认

再次点击当前拼缝或按 `Esc` 退回浏览状态，画布保留刚才的拼合结果。点击“确认拼缝”后显示 `✓ 手动确认`；修改已确认拼缝会重新变为“手动待确认”。

### E. 导出超长图

导出面板先显示完整画布原始像素。例如结果为 `1170 × 52,000 px` 时，不因屏幕预览只有 60% 而改变导出值。若当前格式或环境无法写入单文件，明确显示原因、分段参数和每段尺寸预估。

## 6. 视觉与可用性

- 深色工作台配中性灰侧栏；图像内容保持准确颜色。蓝色只用于选中和可交互的拼缝，绿色勾与琥珀色感叹号同时配文字。
- 工具区保持紧凑：按钮高度 32–40 px，主要点击目标至少 36×36 px。卡片只用于真正独立的列表项或弹窗，不用装饰性容器层层嵌套。
- 图标优先采用现成图标库；不熟悉的图标均有悬停提示和键盘焦点提示。错误通知包含具体拼缝序号与处理入口。
- 图像可能含私密聊天内容。缩略图和画布只在本地显示；最近项目列表允许清空，不在日志中保存图片内容。
- 空、载入中、分析失败、源文件丢失、未保存、导出中、导出完成均须有可见状态和对应操作。

## 7. 原型交付与验收

可点击原型至少覆盖：导入与排序、三模式切换、自动状态分布、点击拼缝进入/退出、鼠标拖动及方向键 1 px 调整、`Shift` 平移、滚轮滚动、`Ctrl` 缩放、清理面板、导出超长图提示。原型可以用模拟图片与模拟匹配数据，但所有状态切换和偏移数值应真实响应操作，不能仅为静态截图。

验收时需重点观察两件事：一是用户能一眼分辨当前在“浏览画布”还是“编辑拼缝”；二是 `Shift + 左键拖动`、滚轮和缩放操作之后，拼缝 X/Y 数值完全不变。
